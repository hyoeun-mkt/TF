1️⃣ 게임별 계정 거래 현황 분석 (영업전략파트 · 정민석)

①
아이온2 / 리니지 클래식 — 거래 금액 높음
아이온2는 20~30대 초반 타깃으로 매니아 유저 풀이 강점입니다.
②
오버워치 / 배그 / LOL — 건수 많고 단가 낮음
랭크 계정, 스킨 보유 계정 위주의 거래입니다.
③
수집형 RPG — 아이디팜에 유저 집중, 매니아 유입 부족
서머너즈워·세븐나이츠 리버스 등은 10대 후반~20대 초반 유저가 아이디팜에 집중되어 있습니다.
④
리니지M / 뱀피르 / RF — 거래 거의 없음
30~40대 유저가 이미 바로템에 정착한 상태입니다.
⑤
SLG — 평균 거래 단가 약 200만원, 등록·구매 채널 분리 패턴
삼국지 전략판·라이즈 오브 킹덤즈 등은 바로템에도 물품이 등록되지만 실제 구매는 매니아에서 이뤄지는 특이 패턴을 보입니다.
결론: 게임별 유저 타깃과 연령층 분석을 바탕으로 차별화 전략이 필요합니다.

2️⃣ 차별화 전략 제안 (영업전략파트 · 전병삼)

기존 경쟁사 방식 답습을 지양하고, 경쟁사에 없는 기능 도입이 필요하다는 방향이 제시됐습니다.
2-1
넥슨 오픈 API 활용 캐릭터 인증
캐릭터명 입력 후 장착 아이템 탈착으로 본인 인증, 스크린샷 없이 닉네임만으로 정보 자동 입력이 가능합니다. 신입사원이 메이플스토리 기반 데모를 제작 완료했습니다. 단, 넥슨 오픈 API 약관상 영리 목적 사용이 불가하여(장재열) — 정보성 사이트는 허용되나 거래 플랫폼은 불허되므로 법무·정책 검토 후 결정이 필요합니다.
2-2
구매자 간편 모드 (미니, 바이어 모드)
상품 종류 선택 → 게임 선택 → 추천 물품 노출의 스텝 형식으로, 깡통 계정·중복 물품을 필터링해 신뢰도 높은 물품만 노출합니다. HTML 프로토타입이 이미 제작 완료됐습니다(전병삼).
2-3
판매자 전문가 모드
세부 정보 입력을 강화해 데이터를 축적하고, 향후 AI 자동화의 기반을 마련합니다.
2-4
계정 쇼츠 영상 제작 서비스
판매자가 정보를 입력하면 아이템·스펙 기반 60초 쇼츠 영상을 제작해 판매 물품 페이지와 유튜브에 자동 업로드합니다. 초기에는 예약제로 소수 운영하며(이성노), AI API 활용 자동화 방향을 검토 중입니다(피노키오 서비스 참고). 인간 검수 단계는 필수로 명시됐습니다(이해성).

3️⃣ 전자계약서 프로세스 개선

현황
판매자 등록 시 서명만 이뤄지고, 구매자는 전자계약서의 존재 자체를 인지하지 못하는 구조입니다.
개선안
바로템 방식을 참고해 구매자 → 판매자 순서로 서명하도록 변경합니다. 판매자에게는 무조건 선(先) 서명을 적용하고, 구매자에게는 전자계약서 이용 여부에 대한 선택권을 부여합니다. 전자계약서 존재 자체를 사이트 내에서 적극 홍보할 필요가 있습니다.
플로우 정리 후 내부 공유 → 이의 없으면 즉시 적용 (담당: 플랫폼기획실 진소영)

4️⃣ 결제 수수료 개선 검토

문제: 마일리지 충전 수수료(1,000원)에 대한 유저 불만이 존재합니다.
제안
계좌 직결제(네이버페이 등 연결 계좌) 도입으로 수수료 없는 결제 수단을 제공합니다(정민석). 계정 거래 카테고리 구매 시에만 수수료 무료 결제 수단을 활성화하며, 어뷰징 위험이 있어 리니지M 파일럿 적용을 우선 제안합니다. 신규 게임 이벤트와 상충 우려가 있어 별도 운영이 필요하고, 수수료 원가(약 1.2%)는 회사가 부담하는 방식입니다.
결론: 수수료 개선은 후순위로 두고, 다른 기능을 먼저 적용한 후 재검토합니다.

5️⃣ 보증 체계 개선 (배경순 CS / 이효찬 RM)

현황
바로템 대비 보증 체계가 미흡해 고객 신뢰도가 낮습니다. 해킹 외 거래 중 영구정지·구글 락 등 사고 발생 시 지원 방법이 부재하며, 전자계약서 존재 자체를 모르는 고객도 다수입니다. 2025년 보상 제도 지급 실적은 약 700만원입니다.
방향
바로템보다 강한 보증 체계를 구축하고, 전자계약서의 법적 효력을 적극 홍보합니다. 이효찬이 하반기 보상 제도 전면 개편 초안을 준비할 예정입니다.
⚠️ 통합 요약 탭에서 5개 부서 자료 중 4건이 독립적으로 지목한 "보증 인프라 최우선" 진단과 정확히 일치하는 회의 결과입니다.

6️⃣ 물품 진열 및 검색 개선 (이효찬 RM / 이성노 플랫폼기획실)

문제
깡통 계정(작업장 계정) 3~4개 업체가 리스트를 도배해 정상 물품이 묻힙니다. 메인 검색에서 계정 관련 키워드 검색 시 결과가 없고, 가격 구간 필터도 부재합니다. 물품 리스트 신뢰도가 낮아 구매 의지가 저하됩니다.
방향
깡통 계정 등록 업자 영구 정지를 추진합니다(개발팀 아이디 산출 후 제재, DB 요청: 조윤성 → RM팀). 계정 카테고리 등록비 부과를 검토하되 게임별 한시적 예외를 적용할 수 있습니다. 가격 구간 필터를 추가하고, 상품 종류 클릭 시 해당 카테고리만 노출하는 게이트웨이 페이지를 도입합니다. 계정/게임머니/아이템 리스트 분리 노출과 다나와식 검색 개선(가격 구간·브랜드 선택 후 정렬)도 검토합니다.

7️⃣ 수수료 무료 결제수단 논의 (사업전략실 · 장재열)

결제
계정 거래 카테고리 내 구매 신청 시에만 계좌 직결제(네이버페이 등)를 활성화합니다. 수수료 원가 약 1.2%, 계정 단가 100~200만원 기준이면 회사 부담 후에도 수익 가능한 수준이며 타 카테고리는 기존 수수료를 유지합니다. 다만 어뷰징 위험(거래마다 마일리지 생성 구조화 우려)이 있어, 리니지M 계정 거래에서 먼저 파일럿 운영 후 단계적 확대를 제안합니다.
다양한 아이디어 중 실제 활성화에 가장 직접적인 핵심 과제 2가지
과제①
스크린샷 OCR 자동 등록
이미지 업로드 시 장비·스펙을 자동 추출합니다 (사내 콘테스트 제안 내용과 동일).
과제②
적정 시세 제안
등록 시 빨리 팔리는 가격 / 정가 / 직접 입력의 3가지 선택지를 제공합니다.
현실적 한계: 인식 정확도가 낮고, 프라이빗 LLM 서버 구축 비용이 약 30억원 수준입니다. 오픈 AI API 수준에서는 텍스트 기반 처리까지만 현실적입니다.
현실적 대안: 유저가 텍스트로 직접 입력하면 AI가 시세를 매칭·추정합니다. 표준화된 캡처 가이드를 제공한 후 제한적으로 OCR을 적용하고, 텍스트 기반 데이터를 축적해 객관적 시세 지표를 형성합니다.

Q1
현재 계정 거래 비중은 전체 거래의 몇 %인가?
TF의 출발점. 계정거래가 얼마나 작은 시장인지, 얼마나 성장 여지가 있는지 가늠하는 지표
Q2
등록자 부족인가? 구매자 부족인가?
이 답에 따라 TF의 전체 방향이 달라짐. 게임별 매물 수 vs 방문자 수 데이터가 핵심 판단 근거
Q3
게임별 계정 거래 TOP10은?
집중 공략할 게임을 선정하는 기준. "게임별 매물 수 TOP20 + 거래량 TOP20" 데이터만 있으면 10분 안에 방향이 나옴
Q4
계정 거래 취소 사유 TOP5는?
안전성·신뢰 문제인지, 가격 문제인지, 매칭 문제인지 파악해야 정확한 처방 가능
Q5
현재 계정 등록 완료율은 몇 %인가?
등록 이탈 구간을 파악하면 가장 빠르게 공급을 늘릴 수 있는 포인트를 찾을 수 있음

📊 계정 판매가 발생하는 6가지 핵심 원인

1
확률형 아이템 시세차익 실현
확률형 뽑기로 고성능 아이템을 저비용에 획득한 유저가 계정을 고가에 매도하여 시세차익을 실현합니다. 반대로 같은 금액을 써도 원하는 아이템을 얻지 못한 유저는 기대가보다 저렴한 계정을 구입합니다. 이 두 집단의 수요·공급이 맞물려 계정거래 시장이 형성됩니다.
2
과금 피로 및 게임 이탈
수십~수백만 원을 투자한 계정을 그냥 버리기 아깝기 때문에, 게임을 그만두면서 투자 비용을 회수하려는 목적으로 계정을 판매합니다. 특히 서비스 종료 예정 게임이나 업데이트 실망으로 이탈하는 유저에게서 공급이 급증합니다.
3
인게임 거래 시스템 부재
많은 모바일 게임이 경매장·거래소 등 인게임 아이템 거래 시스템을 제공하지 않습니다. 아이템 자체를 팔 수 없으니, 아이템이 담긴 계정 전체를 거래하는 방식으로 시장이 대체됩니다.
4
상위 티어 계정의 높은 자산 가치
MMORPG 계정은 최고 수천만 원에 거래됩니다. 강화 수치, 희귀 아이템, 레벨, 스킬 구성 등이 결합된 계정은 희소성이 높아 고가에 형성됩니다. 자산 가치로 인식되어 매물이 지속적으로 등장합니다.
5
플랫폼 간 계정 이동 불가
구글·페이스북·카카오 등 연동 계정 구조로 인해 기기 변경 또는 계정 전환이 어려운 경우, 새 계정 발급 대신 완성된 계정을 구입하려는 수요가 발생하고, 이에 맞춰 공급이 형성됩니다.
6
게임사 묵인 구조 및 법적 공백
현행법상 계정 판매 행위 자체를 처벌하는 규정이 없습니다. 게임사 약관 위반이지만 법적 제재는 없어, 사실상 유저 간 거래가 활발히 이뤄집니다. 게임사도 현거래 유저가 유입될수록 과금 매출이 증가한다는 점에서 적극적 제재에 소극적인 경우가 있습니다.

💡 TF 회의 브리핑용 핵심 인사이트 3가지

①
기능은 대부분 따라잡았다 — 단, 보증 서비스만 예외
결제 전 채팅, 전자계약서 등 핵심 기능은 아이템매니아도 이미 보유하고 있어 격차가 크지 않습니다. 그러나 보증 서비스는 아이템매니아만 부재한 상태로, 4사 비교에서 유일하게 ✕가 찍힌 항목입니다. 단일 기능 격차가 인식 격차로 확대된 사례입니다.
②
계정 거래의 본질은 '안전': 보증 서비스가 시장 인식을 갈랐다
아이템매니아가 아이템 분실·해킹 보상에 머물렀던 사이, 바로템은 회수·탈퇴·영구정지까지 포괄하는 보증 상품(바로패스 등)으로 계정 거래 최대 리스크인 '사후 회수(먹튀)' 문제를 정면 대응했습니다. 전자계약서는 양사 모두 보유한 공통 기능이므로, 차별화의 실제 핵심은 보증 서비스 유무입니다.
③
공급(매물) 유입의 핵심은 '계정 특화 UI'
판매자가 본인 캐릭터의 가치를 시각적으로 어필할 수 있는 이미지 중심 등록 UI가 있었기에 고가 매물이 대거 몰렸습니다. 플랫폼 비즈니스에서 공급이 몰려야 구매자도 유지된다는 원칙을 UI 차원에서 구현한 사례입니다.

🎯 우리 TF가 고려해야 할 전략 방향

A
신뢰 구축이 최우선 — 수수료 이벤트보다 보증 시스템
단순 수수료 인하 이벤트보다는, 우리 플랫폼에서 계정을 샀을 때 "회수 당해도 100% 보상받는다"는 신뢰 시스템(보험/계약서)을 구축하는 것이 최우선입니다. 이것 없이는 초기 유저 유입이 불가합니다.
B
보증 서비스 격차부터 메우는 것이 정책 우선순위
결제 전 채팅·전자계약서는 아이템매니아도 이미 보유한 공통 기능이라 추가 결단이 필요한 영역이 아닙니다. 실질적 격차는 보증 서비스 부재이므로, 보증 범위·가입 프로세스·보상 수치 공개 등 구체적 설계를 TF 내 최우선 논의 안건으로 올릴 것을 권장합니다.
C
틈새 전략 — 바로템이 없거나 약한 장르 공략
타겟 게임 장르(모바일 MMORPG / 스포츠 / 수집형 RPG 등)와 우리 플랫폼만의 기존 강점을 먼저 명확히 한 뒤, 바로템이 강하지 않은 틈새를 집중 공략하는 차별화 전략 수립이 필요합니다.

등록이 귀찮거나 어려운 유저를 위해 MD가 스펙 정리·제목 작성·가격 책정·문의 응대까지 대신해주는 위탁 판매 모델. 고가 계정 판매자(수백만 원 이상)에게 특히 매력적이며, 수수료를 일부 높이는 대신 완전 무관여 거래를 제공합니다.

타겟  고가 계정 보유자 · 등록 방법 모르는 신규 판매자 · 시간 없는 직장인 게이머

계정 상세 페이지에 판매자가 직접 촬영한 플레이 영상 또는 스펙 확인 영상을 첨부하도록 유도합니다. "영상 인증 완료" 배지를 부여하고 노출 우선순위를 높여줍니다. 텍스트·이미지만으로는 확인하기 어려운 실제 계정 상태를 보여줘 구매 확신을 높입니다.

🚀 플랫폼 차별화
08
계정 거래 보험 상품 도입 — "회수 당해도 100% 보상" 차별화

구매 금액의 1~2%를 보험료로 받고, 거래 후 3~12개월 내 계정 회수·정지·해킹 발생 시 구매금액 전액을 보상하는 보험 상품을 도입합니다. 바로템의 바로패스와 유사하지만, 보험사와 제휴해 법적 효력을 강화하면 차별화가 가능합니다. 구매자의 최대 불안 요소를 제거하는 가장 강력한 신뢰 장치입니다.

차별화 포인트  보험사 제휴로 법적 효력 강화 · 바로템 바로패스 대비 신뢰도 우위
09

🔍 왜 졌는가 — 패인 분석

1
출발선의 차이 — 전용 설계 vs 기능 추가
2020년 9월 바로템은 계정거래 전문 플랫폼으로 법인을 설립하고 처음부터 전자계약서·보증을 설계에 반영했습니다. 반면 아이템매니아는 당시 계정거래가 법적 회색지대라 서비스를 운영하지 않았고, 법 개정 이후 기존 아이템 거래 구조에 계정거래 탭을 뒤늦게 추가하는 방식으로 대응했습니다.
2
기능 격차 — 보증 서비스의 '파격성' 부족
전자계약서·결제 전 채팅 등 핵심 기능은 경쟁사 대비 상당 부분 따라잡았으나, 보증 서비스가 없다는 점이 핵심 약점입니다. 아이템땡스는 100~200% 보증, 바로템·아이디팜도 보증 서비스를 운영 중인데 비해 아이템매니아는 보증 서비스 자체가 부재합니다.
3
인식 격차 — "계정거래 = 바로템"
바로템은 계정거래 시장에 인식을 먼저 심었습니다. 아이템매니아는 아이템·게임머니 거래 강자 이미지는 확고하지만 계정거래에서는 브랜드 연상이 약합니다.
4
마케팅 부재 — 신규 유입 전략 차이
바로템은 설립 초기부터 인플루언서·유튜버 파트너십과 SNS 광고로 계정거래 인지도를 빠르게 쌓았습니다. 아이템매니아는 계정거래 추가 이후에도 전면 마케팅을 거의 하지 않았습니다.

AI 기술 도입
